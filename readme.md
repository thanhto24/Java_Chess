# Java Chess ♟️

A full-featured chess application built in **Java**, integrating the **Stockfish engine** for AI gameplay.

## Features
- Human vs Human mode
- Human vs AI mode (powered by Stockfish)
- Chess rules implemented: check, checkmate, stalemate, castling, en passant, pawn promotion
- Graphical interface built with **Java Swing**
- Auto play & move validation
- OOP-based design for maintainability and extension

## Installation
1. Download [Stockfish](https://stockfishchess.org/) and move the `stockfish` folder into the `res` directory.
2. Compile and run the project from `src`.
